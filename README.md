# STH's UI Improvements

A UI/UX improvement mod for *Probably Stolen* (深空当铺).

## Features

1. **Window Snap** — While dragging a floating window, it snaps to screen edges, other windows' edges, and the bottom edge of other windows' **title bars**, with a guide line shown while snapped.
2. **Open to Front** — When you interact (click / double-click) an item whose window is already open, the window is brought to the front instead of being closed.
3. **Box Select** — Hold the box-select key and drag over any cell (empty or occupied) to box-select items.

## Configuration

Open: **Main menu → Mods menu → select "STH's UI Improvements" → gear button**.

| Section | Settings |
|---|---|
| **Window Snap** | Enable (toggle) · Snap mode (Auto / Key) · Snap key · Snap threshold |
| **Open Front** | Enable (toggle) |
| **Box Select** | Enable (toggle) · Force box-select key |

- **Auto** mode: always check for snapping while dragging.
- **Key** mode: only check for snapping while holding the snap key (default LeftShift); releasing it returns to vanilla behavior.

## Installation

- Subscribe on the Steam Workshop, enable it in the in-game Mods menu, then restart.
- Or manually drop the whole mod folder into `Probably Stolen\Mods\STHs_UI_Improvements\`.

## Requirements

- Game version `0.46D`.
