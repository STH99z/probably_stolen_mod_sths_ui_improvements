# STH's UI Improvements

《深空当铺 / Probably Stolen》的界面交互改进 Mod。

## 功能

1. **窗口吸附** —— 拖拽悬浮窗口时自动吸附到屏幕边缘、其它窗口边缘和窗口**顶栏下沿**，并显示一条辅助线。
2. **打开置顶** —— 交互（单击/双击）物品时，若其窗口已打开则**置顶**，而不是关闭。
3. **按键框选** —— 按住框选键，在任意格子（空位或有道具）上拖拽即可框选。

## 配置

入口：**主菜单 → Mods 菜单 → 选中「STH's UI Improvements」→ 齿轮按钮**。

| 分栏 | 设置 |
|---|---|
| **Window Snap**（窗口吸附） | 开启窗口吸附（开关）· 窗口吸附模式（自动 / 按键）· 窗口吸附按键 · 吸附阈值 |
| **Open Front**（打开置顶） | 开启交互物品改为打开窗口并置顶（开关） |
| **Box Select**（框选） | 开启按键框选（开关）· 强制框选按键 |

- **自动** 吸附模式：拖拽时始终检测吸附。
- **按键** 吸附模式：只有按住窗口吸附按键（默认 LeftShift）时才检测吸附，松开即退回原版行为。

## 安装

- 创意工坊订阅后，在游戏 Mods 菜单启用并重启即可。
- 或手动把整个 mod 文件夹放入 `Probably Stolen\Mods\STHs_UI_Improvements\`。

## 要求

- 游戏版本 `0.46D`。
